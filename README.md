# Coffee-Shop-Sales-Analysis
Excel dashboard project analyzing coffee shop sales, footfall, products, and business performance.

## Project Overview
This project analyzes coffee shop sales data using Microsoft Excel to understand sales performance, customer footfall, and product trends.

## Tools Used
- Microsoft Excel
- PivotTables
- PivotCharts
- Slicers
- Data Visualization

## Dashboard Features
- Total Sales
- Total Footfall
- Average Bill per Person
- Average Order per Person
- Hourly Order Analysis
- Category-wise Sales Distribution
- Size-wise Order Distribution
- Sales and Footfall by Store Location
- Top 5 Products by Sales
- Footfall by Weekday

## Project Objective
To analyze coffee shop performance and present useful business insights through an interactive Excel dashboard.
